# SQL por desarrollar

`001_inicio.sql` solo permite comprobar la inicialización; no crea tablas industriales ni introduce registros. Diseñad el esquema, catálogo, ventanas y registro de cargas durante H1–H2.

PostgreSQL ejecuta estos scripts una vez, cuando el volumen está vacío. Las modificaciones posteriores requieren migraciones explícitas. El README principal explica cómo aplicar un archivo SQL sin eliminar el volumen.
